HOW TO MIGRATE:
═══════════════════════════════════════

Step 1: Run the migration script
  $ ./migrate.sh

Step 2: Test locally
  $ npm run dev
  $ open http://localhost:3000

Step 3: Update README
  $ mv README_NEW.md README.md

Step 4: Commit and push
  $ git add .
  $ git commit -m "Restructure for multiple projects"
  $ git push

Step 5: Vercel auto-deploys ✅
